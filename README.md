# موقع النوبة وأسوان — دليل سريع / Nubia & Aswan Website — Quick Guide

## كيف تفتح الموقع
افتح ملف `index.html` مباشرة في أي متصفح، أو ارفع مجلد الموقع بالكامل إلى أي استضافة
ثابتة (Netlify, Vercel, GitHub Pages, cPanel...). لا حاجة لأي تثبيت أو خطوة بناء (build) —
الموقع HTML/CSS/JS خالص ويعمل فورًا.

Open `index.html` directly in a browser, or upload the whole `site/` folder to any static
host (Netlify, Vercel, GitHub Pages, cPanel, etc). No build step or install required.

## البنية / Structure
```
index.html          الصفحة الرئيسية (كل الأقسام)
css/style.css        نظام التصميم الكامل (الألوان، الخطوط، المكوّنات، الحركات)
js/main.js            البيانات (القاموس، المعرض، الاختبار) + كل التفاعلات
assets/images/        كل الصور، بصيغة مصغّرة (thumb) جاهزة للعرض على الويب مباشرة
```

## لتعديل المحتوى دون لمس HTML
أضف كلمات جديدة للقاموس، صورًا للمعرض، أو أسئلة للاختبار من ملف `js/main.js` وحده —
ابحث عن `DICTIONARY`, `GALLERY`, `QUIZ` في أعلى الملف. كل عنصر مصفوفة (array) بسيط،
لا حاجة لأي معرفة برمجية عميقة لإضافة صف جديد.

## قرارات صادقة حول النطاق / Honest scope notes

- **الإطار التقني**: بُني الموقع بـ HTML/CSS/JS مباشرة بدل React/Next.js، لأن الأخير يحتاج
  خطوة بناء (build) لا تناسب ملفًا قابلًا للتنزيل والتشغيل الفوري. النتيجة البصرية والتفاعلية
  مطابقة للمطلوب، لكن الكود ليس مكوّنات React.
- **اللغة الإنجليزية**: الموقع أصبح ثنائي اللغة بالكامل (عربي/إنجليزي) — كل قسم مرئي تقريبًا
  (التنقل، العناوين، الفقرات، القاموس، المعرض، الاختبار، الشخصيات، الحكايات، الشهادات، الأسئلة
  الشائعة، النشرة البريدية) له نص إنجليزي مقابل يظهر فورًا عبر مفتاح AR/EN، بما في ذلك المحتوى
  المولّد ديناميكيًا بجافاسكريبت (بطاقات القاموس، شبكة المعرض، الاختبار، معرض الفيديو) الذي
  يُعاد رسمه تلقائيًا بلغته الصحيحة عند التبديل دون فقدان أي حالة (نتيجة الاختبار، الفيديو
  الجاري تشغيله، الفلتر النشط، المفضلة). النصوص العربية الأصلية محفوظة بالكامل ولم تُمس؛
  الترجمة أُضيفت كطبقة موازية عبر خاصية `data-en` (وامتداداتها `data-en-alt` /
  `data-en-placeholder` / `data-en-aria-label` / `data-en-title` للخصائص غير المرئية)، بحيث
  يسهل تعديل أي ترجمة أو إضافة لغة ثالثة لاحقًا دون المساس بالنص العربي المصدر.
- **حدود الترجمة**: بعض نصوص alt الزخرفية لصور صغيرة غير أساسية (كصور الزينة المتكررة) قد
  تبقى بوسمها العربي الأصلي فقط لأنها لا تُعرض كنص مرئي؛ هذا لا يؤثر على تجربة الإبصار العادية،
  فقط على قارئ الشاشة في وضعية نادرة جدًا.
- **الصور**: تحقّقتُ يدويًا من محتوى كل صورة (وليس فقط اسم الملف)، ووجدت أن جدول الصور المرفق
  في المستند الأصلي كان يصف بعض الصور بشكل غير دقيق (مثال: "aswan-4.jpg" وُصفت كمنظر نيلي
  بانورامي لكنها فعليًا كشك تذكارات). أعدتُ التخصيص بناءً على المحتوى الفعلي، وأعدت تسمية كل
  ملفات الصور بأسماء وصفية واضحة (بدل "images (1).jpg" ونحوها). فحصتُ كل صورة يدويًا: صورتا
  طبقَي الجاكود والكاشيد (قسم المطبخ) تحملان علامة مائية تجارية من مصدرهما الأصلي، وصورة عازفي
  الطار (قسم الموسيقى) هي لوحة فنية عليها توقيع فنان صغير في الزاوية — راجع ملاحظة حقوق الصور
  أدناه قبل النشر الرسمي.
- **المطبخ**: تحتوي هذه النسخة على 5 صور طعام حقيقية (الجاكود، الأرتي، الكاشيد، الملتوت،
  الخمريت) في قسم `#kitchen`.
- **الخريطة**: مضمّنة عبر Google Maps بدون مفتاح API (طريقة embed القياسية)، تعمل فور رفع
  الموقع على أي استضافة حقيقية (رسالة الخطأ التي قد تراها أثناء المعاينة المحلية خاصة ببيئة
  الاختبار فقط).
- **الطقس**: دليل مواسم ثابت (أفضل شهور الزيارة) بدل واجهة طقس حيّة، لأن الطقس الحي يحتاج
  مفتاح API خارجي غير متوفر هنا.
- **نظام إدارة المحتوى (CMS)**: لا يوجد نظام خلفي حقيقي (كان سيتطلب خادمًا وقاعدة بيانات)،
  لكن كل المحتوى القابل للتكرار (القاموس، المعرض، الاختبار) منظّم كبيانات JS منفصلة عن HTML،
  وهي نقطة بداية جيدة لأي تكامل CMS مستقبلي.

## ملاحظة حقوق الصور
كل الصور من مجلد `assets` الذي رفعتَه أنت. بعضها يحمل علامات مائية لمصادر خارجية (مواقع سياحية)
— من الأفضل مراجعتها قبل الاستخدام التجاري الرسمي للموقع.
